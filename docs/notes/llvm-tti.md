# LLVM 的 TTI：目标代价与能力查询接口

> 来源：[`llvm-learning-guide.md`](../llvm-learning-guide.md) §4.6

## 是什么

**TTI（TargetTransformInfo）** 是 LLVM 中端向目标机器询问“能力”和“代价”的接口集合。它本身不是优化算法，而是给优化 pass 提供决策依据：某个操作在目标上是否可用、是否便宜、值不值得展开/向量化/内联。

可以把它理解成中端的“目标咨询窗口”：上层 pass 不直接硬编码某个 ISA 的细节，而是通过 TTI 查询目标相关事实，再决定如何改写 IR。

## TTI 常回答的问题

1. 这个目标的最大向量宽度是多少？
2. `<N x T>` 的某种指令大概有多贵？
3. gather/scatter、mask/predicate 这类操作便不便宜？
4. 展开一个循环或内联一个函数划不划算？
5. 某种地址模式是否容易映射成目标原生寻址形式？

## 关键点

1. **TTI 是面向变换决策的代价模型**，不是通用 IR 分析。
2. **TTI 的结论会直接影响向量化、展开、内联等 pass**。
3. **TTI 填得不准，优化器不一定做错语义，但很可能做出糟糕的性能决策**。
4. **对新后端来说，TTI 往往是中端“看懂硬件”的最重要入口之一**。

## 和其他 Analysis 的区别

| 接口 | 关注点 |
|------|--------|
| DominatorTree | 控制流谁支配谁 |
| LoopInfo | 循环结构 |
| ScalarEvolution | 循环中的数值演化 |
| AliasAnalysis | 指针是否别名 |
| **TTI** | 目标上某种变换/指令的代价与能力 |

## 记忆方式

把 TTI 记成：

> **“LLVM 中端询问目标机器：这件事贵不贵、能不能做、值不值得做。”**
