# 调用图与强连通分量

> 来源：[`llvm-learning-guide.md`](../learning-guides/llvm-learning-guide.md) §3.2

## 是什么

**调用图（call graph）**把程序里的函数当作节点，把“函数 A 调用函数 B”当作有向边。它描述的是函数之间的调用依赖关系。

**强连通分量（SCC, Strongly Connected Component）**是在有向图里一组“彼此都能到达彼此”的节点。放到调用图里，就是一组函数之间形成了调用闭环，通常对应递归关系。

## 关键点

1. **调用图看的是函数层面的依赖关系**，不是单条指令或单个基本块。
2. **SCC 里任意两个函数互相可达**，所以它们常常不能按普通的先后顺序独立优化。
3. **递归可以是直接递归，也可以是间接递归**：
   - 直接递归：`f -> f`
   - 间接递归：`f -> g -> h -> f`
4. LLVM 的 **CGSCC pass** 就是按调用图的 SCC 来调度优化，尤其适合做内联。

## 一个直观例子

```text
A -> B
B -> C
C -> B
D -> E
```

这里的 SCC 可以看成：

- `{A}`
- `{B, C}`
- `{D}`
- `{E}`

其中 `{B, C}` 是一个 SCC，因为它们互相可达，构成了递归环。

## 为什么重要

如果 `B` 和 `C` 互相递归，LLVM 不能简单地把它们当作两个完全独立的函数来优化。把它们放进同一个 SCC 后，优化器可以在一个“函数团”上统一决策，避免因为顺序不当而错失内联或其他优化机会。
