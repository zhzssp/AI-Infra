# =============================================================================
# AI-Infra —— Linux (Debian/Ubuntu) apt 依赖清单
# =============================================================================
# 覆盖仓库动手项目在 Linux 上构建/运行所需的系统包：
#   llvm-hello-compile / mlir-toy-dialect / tvm-fatbin-lab / onnx-delegate-lab
#   以及学习文档中用到的基础工具（git、cmake、python3 等）
#
# 推荐系统：Ubuntu 24.04 LTS（Noble）—— 自带 llvm/mlir 17 包。
# Ubuntu 22.04：若找不到 mlir-17-*，请先加 https://apt.llvm.org/ 再装本清单。
#
# ---------- 一键安装 ----------
#   sudo apt-get update
#   sudo apt-get install -y $(grep -vE '^\s*(#|$)' linux-apt-packages.txt)
#
# 或：
#   grep -vE '^\s*(#|$)' linux-apt-packages.txt | xargs -r sudo apt-get install -y
#
# ---------- apt 装完后仍需（不在本清单）----------
#   # Python 实验室依赖（统一清单）
#   python3 -m venv .venv && source .venv/bin/activate
#   pip install -U pip && pip install -r requirements.txt
#
#   # 可选：ExecuTorch / torch —— 见 requirements.txt 注释与官方文档
#   # 可选：IREE 预编译包 —— https://iree.dev/ （一般不走 apt）
#   # 可选：CUDA Toolkit（fatbin 轨）—— 见下方「可选」注释行，或 NVIDIA 官方 repo
#
# ---------- 版本提示 ----------
# 仓库脚本默认对齐 LLVM/MLIR 17（与 conda-forge mlir-env 一致）。
# 装完后建议：
#   sudo update-alternatives --install /usr/bin/clang clang /usr/bin/clang-17 170
#   sudo update-alternatives --install /usr/bin/clang++ clang++ /usr/bin/clang++-17 170
#   sudo update-alternatives --install /usr/bin/opt opt /usr/bin/opt-17 170
#   sudo update-alternatives --install /usr/bin/llc llc /usr/bin/llc-17 170
#   sudo update-alternatives --install /usr/bin/llvm-config llvm-config /usr/bin/llvm-config-17 170
# =============================================================================
